Estimated peak-hour reactive demand. Per NS-2026, Q_h is the peak-hour value, not a monthly power factor. For each site I computed Q_h = Σ_feeders P_class × tan(acos(PF_class)) − Q_cap,Jan, with PF from the engineering manual (industrial 0.87, maritime 0.88, commercial 0.90, residential 0.95) and Q_cap,Jan = (Q_class,Jan energy − Q_revenue,Jan net)/744 h, the January compensation residual implied by settled revenue meters. December/January/February residuals are near constant per station (e.g. Drangvik 6.797119 Mvar Jan; Malmnes 0.756103; Solberg 7.387719), supporting January compensation at the winter peak. Peak-hour class mix came from feeder SCADA at the peak hour, not monthly averages.

Determined limiting-phase loading. Non-AMI laterals have no telemetry. I estimated their peak single-phase load class-by-class: AMI aggregate peak-hour load per billed MWh set the non-AMI load factor, GIS annual billed MWh set magnitude, and AMI load-weighted peak phase shares set phase allocation. Combining identified/estimated lateral phase loads with one-third of remaining balanced three-phase load gives each phase's total active load (Section 3.2). w_max is the largest phase fraction of total active peak load. I then used the standard exactly: S_15m = sqrt(P_15m² + Q_h²), Lim_MVA = 3 × w_max × S_15m, Loading = 100 × Lim/Firm_N1, Relief = max(0, Lim − 0.85 × Firm_N1). 4. Assumptions and judgment calls.
No direct pool 15-minute metering exists. The standard asks for observed CY2026 peak 15-minute loading, but pool substations have only hourly SCADA plus feeder monthly maxima; PQ 15-minute data exist only for excluded modernized stations. I therefore treat P_15m as an estimate, not an observation, and used PQ strictly as backtest/window selection evidence. A different reasonable peak estimator shifts values; the documented backtest bounds typical value error at about 1.6% MAPE / 2.8% worst interval, but cannot guarantee any single tier.
Residual correlation is a pulse-coincidence proxy. Demand registers measure feeder monthly maxima, and hourly feeder residual correlation measures how batch/maritime loads move together; using it in a correlated root-sum-square is an engineering estimate of coincident 15-minute headroom, not a mandated NS-2026 formula. A simpler independent-pulse RSS would understate synchronized industrial relief; summing registers would overstate it.
Non-AMI phase allocation is estimated, not metered. I assumed non-AMI laterals share AMI class-specific peak load factors and load-weighted phase shares. This is the only pool-wide telemetry-consistent basis; it is not actual non-AMI phase verification. It matters materially at Svarthaug, whose pool load is ~90% single-phase laterals at the evening peak.
Peak-hour Q uses January compensation residual with manual class PF. December-February near-constant residuals support this, but true capacitor dispatch at the exact peak instant is not recorded; monthly revenue energy cannot identify within-month reactive swings. Using only annual/monthly average power factor would misstate peak Q, especially Malmnes (Q_h 15.414461 MVAr vs far lower net monthly ratio implication).
Peak window choice is judgment. Residential/evening sites were evaluated 16:00-20:00 UTC; industrial/mixed weekdays 10:00-15:00; Tverrli uses 17:00 because it scored highest. Raudfjord/Svarthaug and all industrial sites are unambiguous; Tverrli's choice does not affect Defer (worst variant ≈60-61%).
Tverrli's limiting phase/share and exact relief values are near-hour dependent, but its Defer placement and zero relief are robust by >24 points.
15-minute interval within the reported peak hour is not identified; records support an estimated peak and peak hour, not an actual :00/:15/:30/:45 timestamp. I did not fabricate one.
A different reasonable non-AMI phase choice can change Svarthaug sizing (see below); it does not change its Phase 1 timing. A GIS-based choice would also move Drangvik/Kvernholm/Malmnes tiers materially; I rejected it because GIS failed commissioning evidence.
5. Alternatives rejected.
Sum each site's January feeder demand-register maxima as coincident peak. These are monthly per-feeder maxima at different hours/days, not simultaneous; summing systematically overstates coincident peak (the reason the model uses pulse headroom plus correlation instead). It would inflate every site, most severely residential evening sites whose register maxima occur at other hours, and is inconsistent with PQ peaks.
Use SCADA hourly peak directly as P_15m. Rejected because PQ observed 15-minute peaks materially exceed same-hour hourly demand (Dec backtest: Fossheim 39.854 vs 32.624 MW, Lindberg 47.091 vs 31.695 MW, Solberg 36.543 vs 26.837 MW). Skipping uplift would under-relieve Hestmark/Svarthaug/Malmnes and distort Drangvik/Kvernholm.
Use GIS phase for non-AMI laterals because AMI telemetry does not cover them. Rejected as primary evidence: commissioning shows GIS unreliable overall (28/80 = 35.0% agreement), and AMI-versus-GIS across all 220 AMI laterals is 75/220 = 34.1%. This is not merely cosmetic: raw-GIS allocation would move Drangvik to about 101.195% / Phase 1 (relief 7.353 MVA), Kvernholm to about 108.186% / Phase 1 (7.234 MVA), Malmnes to about 98.320% / Phase 2 (5.674 MVA), and Svarthaug to about 135.232% with relief 16.878 rather than filed 8.985 MVA. It would not change Hestmark/Svarthaug/Raudfjord/Tverrli tiers. Filing uses AMI consistently; Svarthaug is explicitly flagged in Method & Validation because it is the one station where GIS agrees with 70% of AMI phases, so its sizing is the least certain filing value even though timing is Phase 1 either way.
Treat Ostervik/Svarthaug-style GIS agreement as proof GIS is generally reliable. Rejected: only 2 of 11 stations show ~70% AMI-GIS agreement; the other nine are ~20-35%, and commissioned Ostervik traces still contradict GIS on 30%.
Portfolio-average loading or budget cap. Rejected by Section 1.2; scheduling is site-by-site. Pooled capacity-weighted loading 93.398510% would wrongly suggest one uniform Phase 2 answer.
Use preliminary SCADA batch (understates by 1.5228%), ignore Raudfjord CET/UTC offset (misaligns peak hour/phases), or treat registers as coincident.
Evidence against the recommendation: Malmnes is only +0.947053 points over Phase 1, inside demonstrated ~1.6% peak-model MAPE; if its true 15-minute peak is more than ~0.403 MVA lower, it belongs in Phase 2 and pool relief falls by its 6.793445 MVA Phase 1 portion/reclassifies. Drangvik is 2.165 points under Phase 1 and would flip if true peak >2.213% higher. I still file Phase 1 for Malmnes and Phase 2 for Drangvik because Section 4 is applied strictly to the best point estimate, and both are explicitly flagged for 15-minute PQ confirmation before capital release; neither uncertainty changes Hestmark/Svarthaug Phase 1, Kvernholm Phase 2, or Raudfjord/Tverrli Defer.
